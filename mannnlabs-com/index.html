Pekerjaan harian, beres lebih cepat.

Contoh ilustrasi — satu cerita, tiga langkah yang nyambung. Mulai dari AI membuatkan file dengan template yang rapi, lalu setiap hari kamu cukup ceritakan pemasukan dan pengeluaranmu untuk dicatat ke file itu, dan di tahap akhir semua catatan itu disusun AI jadi laporan — cukup tulis dengan bahasa biasa. Semua angka di contoh ini hanya ilustrasi, bukan hasil nyata dari pengguna.

09 / FAQ

Yang paling sering ditanyakan

Bisa banget. Kamu hanya perlu mengarahkan base_url ke Mannn Labs dan memakai API key dari kami — format request dan responsenya mengikuti OpenAI, jadi kode lamamu nyaris tidak perlu diubah.

Bayar per paket lewat QRIS, Virtual Account, maupun e-wallet. Begitu pembayaran terkonfirmasi, API key paketmu langsung dikirim ke email. Paket DeepSeek berlaku 1 minggu dan paket Claude berlaku 7 hari; setelah masa berlakunya habis, paket hangus dan tidak ada sisa yang diteruskan ke paket berikutnya (tanpa rollover).

Refund 100% kalau API key tidak bisa dipakai karena kesalahan dari sisi kami, diajukan maksimal 7 hari setelah pembayaran.

Sistem mencatat log sebatas untuk keperluan tagihan dan keamanan. Prompt kamu diteruskan ke penyedia model (DeepSeek / Anthropic) supaya bisa dijawab, dan pembayaran diproses pihak ketiga lewat QRIS, Virtual Account, atau e-wallet. Kami tidak menjual data kamu ke pihak lain untuk iklan, dan kami tidak memakai prompt kamu untuk melatih model.

Pilih DeepSeek kalau kamu butuh jawaban gesit dan irit untuk obrolan, kode, dan tugas harian. Pilih Claude kalau pekerjaanmu banyak berkutat dengan berkas panjang, riset, dan naskah. Masing-masing punya API key sendiri — kalau butuh dua-duanya, beli dua paket: satu paket DeepSeek dan satu paket Claude.

Bukan. Mannn Labs adalah penyedia akses API independen — kami bukan afiliasi resmi, anak perusahaan, atau mitra resmi DeepSeek maupun Anthropic (pembuat Claude). Nama DeepSeek dan Claude kami sebut hanya untuk menjelaskan model yang bisa kamu akses lewat layanan kami.
