      03 / Cara Order

      Dari klik sampai key aktif, tiga langkah saja.

      1PILIH PAKET

      Tentukan paket, lalu sapa kami

      Klik tombol beli pada paket yang kamu mau, atau kirim email ke founder@mannnlabs.com dengan menyebut nama paketnya. Kami balas dengan rincian pembayaran.

      2BAYAR

      Selesaikan pembayaran lokal

      Bayar lewat QRIS, Virtual Account, atau e-wallet — pilih yang paling gampang buatmu. Simpan buktinya, lalu kirimkan ke kami sebagai konfirmasi.

      3TERIMA KEY

      API key meluncur ke emailmu

      Begitu pembayaran terkonfirmasi, API key dan panduan singkat pemakaiannya kami kirim ke email kamu. Tinggal tempel ke aplikasi, dan model siap bekerja.

      Prompt & data diproses secara transparan

      Prompt diteruskan ke penyedia model

      Agar permintaanmu bisa dijawab, prompt diteruskan ke penyedia model (DeepSeek / Anthropic) yang kamu gunakan. Pembayaran diproses oleh pihak ketiga melalui QRIS, Virtual Account, atau e-wallet. Kami tidak menjual datamu untuk iklan, dan kami tidak memakai promptmu untuk melatih model.
